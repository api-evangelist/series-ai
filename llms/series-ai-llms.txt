# Series AI — RUN.world Game Platform

> Series AI (Series Entertainment, Inc.) is an a16z-backed, AI-native game company behind RUN.world, a platform to create, publish, play, and monetize HTML5 games. Developers build games with the RUN.world SDK (@series-inc/rundot-game-sdk) — a single RundotGameAPI import for storage, profiles, leaderboards, ads, purchases, entitlements, multiplayer, server-authoritative simulation, and generative AI — and ship them with the rundot CLI.

Key facts for agents working against this platform:
- The SDK is a client-side JavaScript/TypeScript bridge (React Native JS bridge), not a REST API. Import: `import RundotGameAPI from '@series-inc/rundot-game-sdk/api'`.
- Every RundotGameAPI method returns a promise that can reject; an unhandled rejection crashes the game (fatal RUNTIME_ERROR). Always try/catch awaited calls and .catch() fire-and-forget calls.
- Auth is platform-provided: RUN.world signs players in; games cannot run their own login. CLI/CI uses per-game `rk_` API keys.
- Rate limits surface as HTTP 429 / RateLimitedError with retryAfterMs; detect by `err.code === 'RATE_LIMITED'`.

- [Profiles API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/PROFILE.md): signed-in player identity.
- [Access Gate API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/ACCESS_GATE.md): require sign-in / gate features.
- [Leaderboards API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/LEADERBOARD.md): scores and moderation.
- [Ad Monetization API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/ADS.md): rewarded and interstitial ads.
- [Purchases API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/PURCHASES.md): spend RunBucks on digital goods.

- [Multiplayer API](https://github.com/series-ai/venus-sdk-docs/blob/main/rundot-developer-platform/api/MULTIPLAYER.md): real-time sessions (BETA).
